# Quran Masterclass

Verse-by-verse Quran listening with tafsir (German / English, more languages later).

- `CLAUDE.md` – full project brief, decisions, server info and roadmap (read this first in Claude Code)
- `prototype/index.html` – working single-file prototype (open in a browser)
- `scripts/server-setup.sh` – base setup for the plain Ubuntu 24.04 VPS
- `scripts/download-audio.sh` – downloads per-verse recitation audio to the VPS
